# VideoTube frontend

React + Vite frontend for the backend in `../backend-project`.

## Run locally

1. Start the backend with its required environment variables.
2. Copy `.env.example` to `.env` if the backend is not on `http://localhost:4000`.
3. Install and run:

```bash
npm install
npm run dev
```

The backend CORS origin must match the Vite origin (normally `http://localhost:5173`).
